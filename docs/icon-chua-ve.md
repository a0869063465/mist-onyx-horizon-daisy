# Kho icon chưa được vẽ

Skill đang dùng icon có sẵn tạm. Chủ game vẽ xong thì thay file ảnh `public/ui/skill/<id>.webp` và thêm id vào `src/lib/skill-art-ids.ts`.

| Lá | Skill | Icon tạm (game-icons) | Ghi chú |
|---|---|---|---|
| Nắng và gió (`nang-va-gio`) | Gió dịu đi (nội tại, hồng) | `whirlwind` | 22/11 |
| Nắng và gió (`nang-va-gio`) | Nắng ấm lên (chủ động, chậm) | `flame-spin` | 22/11 |
| Rùa máy bắn đá (`rua-may-ban-da`) | Pháo kích (chủ động, chậm) | `cannon-shot` | 23/11 |
| Thiên thần hạnh phúc (`thien-than-hanh-phuc`) | Tia sáng hạnh phúc (ngoài giao tranh) | `angel-wings` | 23/11 |
